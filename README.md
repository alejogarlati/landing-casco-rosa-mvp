# Fundación El Casco Rosa — Web Platform (MVP)

Institutional web platform and informational landing page designed and developed for **Fundación El Casco Rosa** (breast cancer awareness and support organization in Tucumán, Argentina).

🔗 **Live Demo:** [landing-casco-rosa-mvp.vercel.app](https://landing-casco-rosa-mvp.vercel.app)

---

## Overview & UI Focus

- **Clear Information Architecture:** Multi-section navigation (`Home`, `Quiénes Somos`, `Qué Hacemos`, `Casos`, `Contacto`) designed to communicate institutional impact and facilitate outreach.
- **Accessible & Calm Visual Hierarchy:** Clean typography, structured spacing, and smooth motion cues powered by **Framer Motion**.
- **Responsive Mobile-First Layout:** Modular React components styled with **Tailwind CSS v4**.

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Styling:** React 19, TypeScript, Tailwind CSS v4, Lucide React
- **Motion:** Framer Motion
- **Deployment:** Vercel

---

## Local Development

```bash
npm install
npm run dev
```
